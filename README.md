# construction-management-app

## Chantier+ (nouvelle plateforme) → [`plateforme/`](plateforme/README.md)

Plateforme de pilotage de projets d'infrastructure pour directeurs de projet et responsables de lot : finances par CFC, appels d'offres CAN, contrats SIA 118, factures, planning Gantt, documents SharePoint, ressources et assistant IA.

```bash
cd plateforme && npm install && npm run dev
```

## Application historique

L'application de suivi financier d'origine (`index.html`, `app.js`, `components/`) reste disponible (`DEMARRER.bat` / `demarrer.sh`). Ses données peuvent être importées dans Chantier+ (Paramètres → Importer une session).
